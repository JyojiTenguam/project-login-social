# 📱 Projeto Login Social

Projeto desenvolvido em Android nativo com Java durante o curso da Trybe, com o objetivo de implementar um fluxo de autenticação utilizando login social com Google e Facebook. A aplicação permite que usuários acessem a plataforma utilizando suas contas dessas redes sociais de forma segura.

## ✨ Demonstração

> A aplicação apresenta uma interface simples e funcional onde o usuário pode realizar login com Google ou Facebook. Após o login, os dados são exibidos na tela de perfil, incluindo nome e foto do usuário.

## 💡 Sobre

O projeto tem como foco a **integração de login social** com provedores como Google e Facebook utilizando as respectivas SDKs oficiais. Ele foi desenvolvido como parte do cronograma do módulo de Android da Trybe, visando consolidar práticas de autenticação segura e integração com APIs externas.

## 🛠️ Habilidades desenvolvidas

- Integração com SDK do Google Sign-In
- Integração com SDK do Facebook Login
- Gerenciamento de sessões e autenticação de usuários
- Manipulação de intents e callbacks no Android
- Implementação de telas responsivas em XML
- Tratamento de erros e estados de login

## 🧪 Tecnologias utilizadas

- Java
- Android SDK
- Google Sign-In SDK
- Facebook SDK
- Firebase Authentication (para suporte)
- Gradle

## 🚀 Como rodar o projeto

1. Clone o repositório:

   ```bash
   git clone git@github.com:tryber/android-039-android-projeto-login-social.git
   ```

2. Abra o projeto no Android Studio

3. Sincronize as dependências com o Gradle

4. Compile e execute o projeto em um dispositivo Android ou emulador
> A aplicação estará disponível para visualização no dispositivo/emulador.
